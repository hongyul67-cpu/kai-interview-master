# KAI 면접 마스터

기계공고 학생이 **한국항공우주산업(KAI) 생산기술·기체 조립 직무** 면접을 준비하는 학습도구입니다.
기체 조립에 필요한 이론을 배우고, 그 이론이 조립 현장에서 어떻게 쓰이는지 대응표로 익힌 뒤,
점검 퀴즈와 소리 내어 답하는 면접 연습으로 마무리합니다.

- 주소 : https://hongyul67-cpu.github.io/kai-interview-master/
- 대상 : 기계공고 3학년 — KAI 생산직·기술직(기체 조립·생산기술) 지원자
- 만든 곳 : 경기기계공업고등학교 취업지원부
- 만든 날 : 2026-09-30

## 구성

탭 5개입니다. 배우기(정답을 다 보여 줌)를 앞에, 퀴즈·면접 연습을 뒤에 둡니다.

| 탭 | 내용 |
|---|---|
| 🏠 홈 | 진행 현황 · 계급 배지 · 공식 사이트 안내 |
| 📖 배우기 | 단원 10개(L1~L10) — 요약 · 섹션 · 용어 · 출처. 교재 밖 내용은 「교재 밖 실무 지식」 딱지 |
| 🏭 현장 대응표 | 전 단원의 「이론 → KAI 조립 현장 → 잘못되면」 표(77줄), 단원 필터. 좁은 화면에서는 카드로 바뀜 |
| ✅ 점검 퀴즈 | 연습 8문항(즉시 정답·해설) / 종합시험 20문항(끝까지 비공개 → 오답노트 → 제출) |
| 🎤 면접 연습 | 예상 질문 59개(기술 ①·② · 인성·상황 · 회사·직무) — 아코디언, 60초 말하기 연습, 키워드 자기평가, 📌 다시 볼 질문, 무작위 모의면접 5문항 → 제출 |

| 단원 | 내용 |
|---|---|
| L1 | 기체 구조 — 세미모노코크·응력·구조부재·스테이션 |
| L2 | 리벳·판금 조립 — 리벳 규격·배치·드릴·카운터싱크·불량 |
| L3 | 특수 패스너·하드웨어·토크·안전결선 |
| L4 | 부식·실링·표면처리 |
| L5 | 복합재료·샌드위치 구조 |
| L6 | 비파괴검사(NDT)·검사 |
| L7 | 항공기 도면·공차·측정 |
| L8 | 항공기 금속재료·열처리 |
| L9 | 생산기술 실무 — 치구·BOM·작업표준·GD&T·5Why·FOD·인적요인 |
| L10 | KAI 회사·제품·직무 이해(공식 자료 확인, 출처·확인 날짜 포함) |

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 틀 — 데이터 14개를 고정 이름으로 불러오고, 없는 파일은 건너뜀 |
| `app.js` · `style.css` | 화면(홈·배우기·현장 대응표·면접 연습) |
| `quiz.js` | 점검 퀴즈(연습·종합시험·오답노트·제출) |
| `data/L1.js` … `data/L10.js` | 배우기 단원 — `KAI.learn.push({...})` |
| `data/I1.js` … `data/I4.js` | 면접 질문 — `KAI.iv.push({...})` |
| `rubric.json` | 결과수집이 수준·세특 문장을 만들 때 쓰는 루브릭 |

## 고칠 곳

- 내용은 `data/` 파일만 고치면 됩니다. 한 파일 = 한 단원(또는 면접 분류)입니다.
- 퀴즈 문항은 각 단원의 `check` 배열 — 정답 위치(`a`)를 0~3에 고르게, 해설에 보기 번호를 쓰지 않습니다.
- 고친 뒤 문법 검사: `node --check data/L3.js`
- 결과 제출 `mode` : `KAI 면접 마스터 — 종합시험` 류 / `KAI 면접 마스터 — 모의면접`

## 원자료와 저작권

- 국토교통부 항공정비사 표준교재(항공기 기체 · 항공정비일반) — **요약·재서술만** 했고, 문장·그림을 옮기지 않았습니다.
  그림은 직접 그린 SVG 입니다. 출처는 교재 쪽번호로 적었습니다.
- 교재 밖 내용(치구·BOM·GD&T·5Why 등)은 「교재 밖 실무 지식」으로 표시했습니다.
- 회사 정보는 KAI 공식 홈페이지·채용 홈페이지에서 확인한 것만, 확인 날짜와 함께 넣었습니다.
- 면접 질문은 모두 **예상 질문**입니다(기출 아님).
- 최신 자료는 KAI 채용 홈페이지와 국토교통부 항공교육훈련포털을 직접 확인하세요.
